# V2 Release Notes

## Highlights

- Added YouTube quality selection before download
- Added separate audio-only download support for YouTube videos
- Added a new File Tools section with:
  - Video Compressor
  - Audio Compressor
  - PDF Compressor
  - PDF Slicer
  - PDF Merger
- Added automatic splitting of large compressed audio and video outputs into parts below 16 MB for easier delivery in messaging apps with strict file size limits
- Improved the News section so each message uses Telegram message space more efficiently and carries more useful information with less wasted space
- Added a direct Gemini chat entry from the main AI menu

## Upgrade Notes

- The bot now uses a cleaner multi-level Persian menu
- The main AI section is now a general Gemini chat entry point
- The news-aware AI chat remains available inside the News section
- The release build removes local user-registration storage and does not include runtime user data
